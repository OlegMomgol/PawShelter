# Схема базы данных PawShelter

## 1. Общая характеристика БД
- **Имя базы данных:** `PawShelter` (экземпляр `localhost\SQLEXPRESS`)
- **СУБД:** Microsoft SQL Server Express
- **Количество таблиц:** 6 нормализованных таблиц (3НФ)
- **Визуальная диаграмма:** [database-schema.svg](./database-schema.svg)

---

## 2. Описание таблиц и атрибутов

### 2.1. `Species` — Справочник видов животных
Хранит перечень биологических видов, принимаемых в приют (например: *Кошка*, *Собака*, *Кролик*).

| Столбец | Тип данных | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `Id` | `INT` | `PRIMARY KEY IDENTITY(1,1)` | Уникальный идентификатор вида |
| `Name` | `NVARCHAR(100)` | `NOT NULL, UNIQUE` | Наименование вида животного |

---

### 2.2. `Enclosures` — Вольеры приюта
Хранит сведения о вольерах, их максимальной вместимости, текущей заполненности и доступности для заселения.

| Столбец | Тип данных | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `Id` | `INT` | `PRIMARY KEY IDENTITY(1,1)` | Уникальный идентификатор вольера |
| `Code` | `NVARCHAR(30)` | `NOT NULL, UNIQUE` | Код вольера (например, `B-101`, `K-201`) |
| `Capacity` | `INT` | `NOT NULL, CHECK (Capacity > 0)` | Максимальное количество мест |
| `CurrentCount` | `INT` | `NOT NULL, DEFAULT 0, CHECK (CurrentCount >= 0)` | Текущее количество животных в вольере |
| `Status` | `NVARCHAR(30)` | `NOT NULL, DEFAULT N'Открыт'` | Состояние вольера (`Открыт`, `Закрыт`, `На ремонте`) |

---

### 2.3. `Animals` — Основной реестр животных
Центральная таблица системы, содержащая карточки животных, их привязку к виду и вольеру, а также текущий статус.

| Столбец | Тип данных | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `Id` | `INT` | `PRIMARY KEY IDENTITY(1,1)` | Уникальный идентификатор животного |
| `Name` | `NVARCHAR(100)` | `NOT NULL` | Кличка животного |
| `SpeciesId` | `INT` | `NOT NULL, FK -> Species(Id)` | Ссылка на вид животного |
| `EnclosureId` | `INT` | `NULL, FK -> Enclosures(Id)` | Ссылка на вольер (`NULL`, если без вольера) |
| `AgeYears` | `DECIMAL(4,1)` | `NOT NULL, CHECK (AgeYears >= 0)` | Возраст в годах |
| `AdmissionDate` | `DATE` | `NOT NULL, DEFAULT GETDATE()` | Дата поступления в приют |
| `Status` | `NVARCHAR(30)` | `NOT NULL, DEFAULT N'В приюте'` | Статус (`В приюте`, `На лечении`, `Передан`) |
| `IsArchived` | `BIT` | `NOT NULL, DEFAULT 0` | Флаг архивации (`0` — активен, `1` — в архиве) |

---

### 2.4. `Adopters` — Усыновители
Справочник физических лиц, подающих заявки на передачу животных.

| Столбец | Тип данных | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `Id` | `INT` | `PRIMARY KEY IDENTITY(1,1)` | Уникальный идентификатор усыновителя |
| `FullName` | `NVARCHAR(150)` | `NOT NULL` | ФИО усыновителя |
| `Phone` | `NVARCHAR(30)` | `NOT NULL` | Контактный телефон |
| `Email` | `NVARCHAR(100)` | `NULL` | Электронная почта |
| `IsBlacklisted` | `BIT` | `NOT NULL, DEFAULT 0` | Признак неблагонадёжного заявителя |

---

### 2.5. `MedicalRecords` — Медицинские записи
Журнал ветеринарных осмотров, диагнозов и вакцинаций.

| Столбец | Тип данных | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `Id` | `INT` | `PRIMARY KEY IDENTITY(1,1)` | Уникальный идентификатор записи |
| `AnimalId` | `INT` | `NOT NULL, FK -> Animals(Id)` | Ссылка на животное |
| `RecordDate` | `DATE` | `NOT NULL, DEFAULT GETDATE()` | Дата осмотра |
| `Diagnosis` | `NVARCHAR(250)` | `NOT NULL` | Заключение / диагноз ветеринара |
| `VaccinationDone` | `BIT` | `NOT NULL, DEFAULT 0` | Отметка о проведённой вакцинации |

---

### 2.6. `Adoptions` — Передачи животных (усыновления)
Журнал оформления передачи животных новым владельцам.

| Столбец | Тип данных | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `Id` | `INT` | `PRIMARY KEY IDENTITY(1,1)` | Уникальный идентификатор акта передачи |
| `AnimalId` | `INT` | `NOT NULL, FK -> Animals(Id)` | Ссылка на переданное животное |
| `AdopterId` | `INT` | `NOT NULL, FK -> Adopters(Id)` | Ссылка на усыновителя |
| `AdoptionDate` | `DATE` | `NOT NULL, DEFAULT GETDATE()` | Дата передачи |
| `Notes` | `NVARCHAR(300)` | `NULL` | Дополнительные примечания |

---

## 3. Связи между таблицами (ER-модель)
- `Species (1) ──< (N) Animals`: каждому виду может соответствовать множество животных.
- `Enclosures (1) ──< (N) Animals`: в одном вольере может содержаться несколько животных (в пределах `Capacity`); связь опциональная (`EnclosureId` допускает `NULL`).
- `Animals (1) ──< (N) MedicalRecords`: для одного животного ведётся история ветеринарных осмотров.
- `Animals (1) ──< (N) Adoptions` и `Adopters (1) ──< (N) Adoptions`: таблица `Adoptions` связывает животное и усыновителя при оформлении передачи.
