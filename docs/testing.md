# План и результаты тестирования PawShelter

## 1. Среда тестирования
- **ОС:** Windows 10 / 11
- **Среда разработки:** Visual Studio 2022 (`.NET` / WPF)
- **СУБД:** Microsoft SQL Server Express (`localhost\SQLEXPRESS`, БД `PawShelter`)
- **Начальные данные:** тестовый набор из SQL-скрипта (`Барсик`, `Рекс`, `Луна`, `Кеша`, `Эрик` и др.)

---

## 2. Функциональные и негативные тест-кейсы

| ID | Сценарий | Шаги выполнения | Ожидаемый результат | Статус |
| :--- | :--- | :--- | :--- | :--- |
| **TC-01** | Загрузка реестра при старте приложения | Запустить `PawShelter.exe` (`F5`). | Открывается главное окно в коричневой теме; в таблице `AnimalsGrid` загружены активные животные (`IsArchived = 0`), заполнены списки видов и открытых вольеров. | Выполнено |
| **TC-02** | Поиск по части клички | Ввести `Рек` в поле «Кличка» и нажать «Найти / Обновить». | В таблице остаётся только запись `Рекс`. | Выполнено |
| **TC-03** | Комбинированная фильтрация и сброс | Выбрать вид `Собака`, статус `В приюте`, нажать «Найти / Обновить», затем нажать «Сбросить». | Сначала отображаются только собаки со статусом `В приюте`, после сброса возвращается полный список активных животных. | Выполнено |
| **TC-04** | Успешное добавление животного в открытый вольер | Ввести кличку `Мурка`, выбрать вид `Кошка`, вольер `K-201`, возраст `1.5`, нажать «+ Добавить». | В БД добавляется запись `Мурка`, `CurrentCount` вольера `K-201` увеличивается на 1 в рамках транзакции, таблица обновляется. | Выполнено |
| **TC-05** | Добавление животного без вольера | Ввести кличку `Снежок`, выбрать `Без вольера`, возраст `2.0`, нажать «+ Добавить». | Животное сохраняется с `EnclosureId = NULL`, в таблице отображается `Без вольера`, счётчики вольеров не меняются. | Выполнено |
| **TC-06** | Негативный тест: пустая кличка | Оставить поле «Кличка» пустым и нажать «+ Добавить». | Появляется предупреждение о необходимости ввести кличку; запрос в БД не выполняется. | Выполнено |
| **TC-07** | Негативный тест: некорректный возраст | Ввести `abc` или `-3` в поле «Возраст» и нажать «+ Добавить». | Выводится сообщение об ошибке формата/значения возраста; запись в БД не создаётся. | Выполнено |
| **TC-08** | Изменение статуса животного и освобождение места | Выбрать животное в вольере, выбрать новый статус `Передан` и нажать «Сохранить статус». | Статус обновляется на `Передан`, место в вольере освобождается (`CurrentCount` уменьшается на 1) в одной транзакции. | Выполнено |
| **TC-09** | Негативный тест: смена статуса у переданного животного | Выбрать запись со статусом `Передан` и попытаться изменить статус на `В приюте`. | Срабатывает бизнес-правило запрета возврата переданного животного; транзакция откатывается, отображается сообщение. | Выполнено |
| **TC-10** | Архивирование записи | Выбрать активное животное в таблице и нажать «В архив». | Поле `IsArchived` устанавливается в `1`, запись скрывается из таблицы, занятое место в вольере освобождается. | Выполнено |
| **TC-11** | Формирование сводного отчёта | Нажать кнопку «Сводный отчёт» в шапке окна. | Открывается окно с актуальной сводкой по количеству животных по видам, статусам и свободных местах в вольерах. | Выполнено |

## 3. Проверка пользовательского интерфейса
- Проверена контрастность белого текста (`#FFFFFF`) на тёмно-коричневом фоне карточек (`#3C291F`) и ячеек таблицы (`#34231A`).
- Проверено корректное отображение текстовых значений (`DisplayMemberPath="Name"` и `DisplayMemberPath="Code"`) во всех выпадающих списках (`ComboBox`) без отображения имён C#-классов.
