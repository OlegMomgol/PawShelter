# PawShelter — приют для животных

## Назначение системы

Сотрудник ведёт реестр животных в приюте, подбирает вид и вольер, контролирует вместимость вольеров и обновляет статусы подопечных. Передача животного или архивирование корректно обновляют состояние записи и освобождают место в вольере. Сводные показатели помогают контролировать загрузку приюта.

## Реализованные возможности

| Возможность | Что может сделать сотрудник | Состояние |
| :--- | :--- | :--- |
| **Реестр животных** | Найти животное по кличке, отфильтровать по виду или статусу, сбросить фильтры и обновить список | Реализовано |
| **Приём и заселение** | Указать кличку, вид, вольер и возраст, добавить животное и занять место в открытом вольере | Реализовано |
| **Статусы и архив** | Изменить статус выбранного животного (*В приюте*, *На лечении*, *Передан*) или отправить запись в архив с освобождением места | Реализовано |
| **Сводный отчёт** | Посмотреть сводку по животным, видам, статусам и загруженности вольеров | Реализовано |
| **Оформление интерфейса** | Работать в тёмно-коричневом интерфейсе с белым текстом и кастомными стилями таблицы и выпадающих списков | Реализовано |

## Запуск на другом компьютере

### 1. Подготовка
Скачайте или клонируйте репозиторий. Установите .NET SDK для Windows, Visual Studio с поддержкой WPF и **Microsoft SQL Server Express**. Откройте терминал или PowerShell в корневой папке репозитория.

### 2. Развёртывание базы данных
При первом запуске создайте базу и таблицы, а затем загрузите тестовые данные:
1. Выполните скрипт `database/schema.sql` для создания базы `PawShelterDB` и 6 таблиц (`Species`, `Enclosures`, `Animals`, `Adopters`, `MedicalRecords`, `Adoptions`).
2. Выполните скрипт `database/seed.sql` для заполнения справочников, вольеров, животных, усыновителей и медицинских записей.

### 3. Настройка подключения
По умолчанию приложение подключается к базе `PawShelterDB` на локальном экземпляре SQL Server Express (`localhost\SQLEXPRESS`). При необходимости проверьте строку подключения в классе работы с БД (`DatabaseService.cs`) перед запуском.

### 4. Запуск приложения
* В **Visual Studio** откройте решение/проект из папки `src/` и нажмите `F5`.
* В **PowerShell** выполните сборку и запуск проекта из папки `src/`:

В PowerShell выполните команду из корня проекта
 `dotnet run --project src/PawShelter/PawShelter.csproj`
