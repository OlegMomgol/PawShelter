# PawShelter — Информационная система управления приютом для животных

Настольное приложение на **C#**, **WPF**, **MS SQL Server** и **ADO.NET** (тема № 08 — *PawShelter: Приют для животных*).

## Состав репозитория
- `src/PawShelter/` — решение и исходный код приложения (`PawShelter.sln`, `PawShelter.csproj`, окна и экраны WPF, слой доступа к данным на ADO.NET, бизнес-логика и отчёты).
- `database/schema.sql` — DDL-скрипт создания базы данных (`PawShelterDb`), 6 связанных таблиц, первичных/внешних ключей и ограничений целостности.
- `database/seed.sql` — тестовые данные по всем таблицам (виды/породы, вольеры, животные, кураторы/усыновители, заявки/оформление усыновления, медицинские осмотры/прививки).
- `docs/requirements.md` — функциональные и нефункциональные требования, сценарии и бизнес-правила.
- `docs/database-schema.md` и `docs/database-schema.svg` — описание ER-модели, связей и векторная схема.
- `docs/testing.md` — тестовые сценарии (включая позитивные и негативные проверки транзакций и ограничений).

## Быстрый запуск
1. Выполните в SQL Server Management Studio (или `sqlcmd`) сначала `database/schema.sql`, затем `database/seed.sql`.
2. Проверьте строку подключения в `src/PawShelter/appsettings.json` (при необходимости создайте `appsettings.Local.json`).
3. Откройте `src/PawShelter/src/PawShelter.sln` в Visual Studio 2022 и запустите проект (`F5`).
